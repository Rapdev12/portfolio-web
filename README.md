# 🚀 Ronald Palacios - Portfolio Web

Personal portfolio website built to showcase my projects, skills, and professional background as a web developer. Designed with a modern, clean aesthetics featuring custom layouts, interactive elements, and a fully responsive structure.

![Vite](https://img.shields.io/badge/Vite-Bundler-purple?style=for-the-badge&logo=vite)

---

## ✨ Features

- **Modern & Clean UI:** Designed with a professional dark/light contrast system, cohesive violet brand accents (`#7c3aed`), and smooth transitions.
- **Interactive Hero Section:** Features a custom code-editor mockup component highlighting developer stack and details.
- **Responsive Navigation:** Smooth routing and persistent state handling using React Router.
- **Project Showcase:** Dynamic grid layout for displaying recent works with interactive hover effects and GitHub links.
- **Professional Footer:** High-contrast dark closing block mirroring the header identity.

---

## 🛠️ Tech Stack

- **Frontend Library:** [React](https://react.dev/)
- **Build Tool:** [Vite](https://vitejs.dev/)
- **Routing:** [React Router](https://reactrouter.com/)
- **Styling:** Vanilla CSS (Modular, custom properties, Flexbox & Grid)
- **Typography:** [Plus Jakarta Sans](https://fonts.google.com/specimen/Plus+Jakarta+Sans)
